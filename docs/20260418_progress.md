### 3.3 Five-config sweep 흐름 (`main` in default mode)

```
memcpy srcnn_input (22500) → DDR_INPUT   [1회]
for c in CONFIGS[0..4]:
    run_one_config(cfg):
        for layer in {L1, L2, L3}:
            run_hwpe_layer(w, b, in_ch, out_ch, k, ...)
                for pass in 0..ceil(out_ch/4)-1:
                    run_hwpe_pass(...)     // HW 1회 실행 per pass
                    (per pass 내부: 배치 루프 + cycle count 누적)
        verify vs cfg->golden (22500 pixel exhaustive)
        print util  useful_MACs / (compute_cycles × 64)
```

### 3.4 Multi-pass (out_ch > 4 대응, SW-only)

HWPE의 physical `MAX_OUT_CH=4`. SW가 out_ch를 4단위로 쪼개 반복 호출.

```c
int passes = (out_ch + 3) / 4;
for (int p = 0; p < passes; p++) {
    int pass_out = (out_ch - p*4 > 4) ? 4 : out_ch - p*4;
    const int16_t *w_p = weights + p * 4 * k_total;       // weight offset
    const int16_t *b_p = bias    + p * 4;                 // bias offset
    uint32_t out_p     = out_addr + p * 4 * N_PIX_PAD * 2;// DDR channel offset
    run_hwpe_pass(w_p, b_p, in_ch, pass_out, k_total, ..., out_p);
}
```

HWPE는 multi-pass 존재를 모름. 드라이버가 3개 오프셋만 바꿔 반복 실행.

### 3.5 Mode B auto-select (per pass 진입 시)

```c
int mode_b = (out_ch_pass == 1 && g_mode_b) ? 1 : 0;
hwpe_wr(REG_MODE, mode_b);
```

- `g_mode_b = (out_ch_total == 1)` — run_hwpe_layer 진입 시 1회 결정
- Mode B는 항상 single pass (out_ch=1이므로 자연히 1 pass)

## 4. HW 구조

### 4.1 모듈 계층

```
                   APB CSR         AXI master (DDR3)       TCDM master 0..3 (L2 weight)
                      │                  │                         │
                      ▼                  ▼                         ▼
              ┌─────────────────────────────────────────────────────┐
              │                  fc_hwpe (top FSM)                 │
              │  S_IDLE → S_IM2COL → S_DMA_LOAD → S_LOAD_W →       │
              │  S_RUN → S_DONE → S_IDLE                           │
              └─────────────────────────────────────────────────────┘
                 │            │              │          │             │
       ┌─────────┤            │              │          │             │
       ▼         ▼            ▼              ▼          ▼             ▼
  hwpe_im2col  hwpe_axi_dma  hwpe_weight_buf  hwpe_systolic  hwpe_post_proc
  (input→      (DDR→4-bank   (TCDM→FF        (4×16=64 PE,   (int32→int16,
   line buf    partitioned   register        K ≤ 144)       AXI write)
   → DDR)     BRAM)         9216-bit)
```

### 4.2 FSM 흐름 (1 batch 기준)

| 상태 | 담당 | 동작 |
|---|---|---|
| S_IDLE | — | CSR 세팅 완료 대기, `start_pulse` 감지 |
| S_IM2COL | hwpe_im2col | DDR 입력 → line buffer → 3×3 kernel 확장 → im2col matrix를 DDR에 기록 |
| S_DMA_LOAD | hwpe_axi_dma | DDR im2col → BRAM (4-bank partition, double-buffer swap) |
| S_LOAD_W | hwpe_weight_buf | L2 TCDM → FF register array (out_ch × k_total × int16) |
| S_RUN | hwpe_systolic_array + hwpe_post_proc | Systolic K cycle 누적 → drain → post_proc → AXI write |
| S_DONE | — | `done_q` 1-cycle, S_IDLE 복귀 |

### 4.3 Mode A vs Mode B (S_RUN 내부)

| | Mode A (out_ch ≥ 2) | Mode B (out_ch = 1) |
|---|---|---|
| PE 논리 배치 | 4 row × 16 col | 1 row × 64 col |
| Activation/cycle | 16 × int16 = **256-bit** (1 bank) | 64 × int16 = **1024-bit** (4 bank 병렬) |
| Weight/cycle | `weight[r][k_q]` 4 row × 16-bit = **64-bit** | `weight[0][k_q]` = **16-bit broadcast** |
| Output tile | 16 pix × 4 ch | 64 pix × 1 ch |
| Drain + AXI write | 16 pix fill + `out_ch` × 1-beat write | 64 pix fill + **4-beat INCR burst** |

## 5. 모듈별 Cycle당 I/O Bit-width

### 5.1 fc_hwpe (top)

| 인터페이스 | 방향 | Cycle당 bit | 비고 |
|---|---|---|---|
| APB CSR | slave bidir | ADDR 32b, DATA 32b | CPU ↔ CSR read/write |
| AXI AR/R | master | ADDR 32b, DATA **256 b/beat** | DDR3 read (im2col input, im2col matrix) |
| AXI AW/W/B | master | ADDR 32b, DATA **256 b/beat** | DDR3 write (im2col matrix, post_proc out) |
| TCDM 0~3 | master × 4 | ADDR 32b, DATA 32b, BE 4b | L2 weight/bias read — port 1만 실사용 |

### 5.2 hwpe_im2col (input→line buffer→DDR)

| 단계 | 신호 | Cycle당 bit |
|---|---|---|
| S_LOAD_R (DDR 읽기) | `axi_r_data_i` | **256 b/beat** = 16 pix |
| Line buffer write | `buf_wdata` → 4 replica × 256-bit | 256 b/cycle per active bank |
| S_COMP 5-phase | `buf_rword[lane]` × 4 lane | 4 × 256 b = **1024 b/cycle 병렬 read** |
| COMP extract | `lane_pix_off_r` → 16-bit extract × 4 lane | 64 b/cycle 출력 buffer로 |
| S_W (DDR 쓰기) | `axi_w_data_o` | **256 b/beat** = 16 pix |

> Line buffer 4-replica 덕에 1024 b/cycle parallel read 가능 → 5 cycle마다 16-pix AXI beat 생성.

### 5.3 hwpe_axi_dma (DDR→BRAM 4-bank)

| 인터페이스 | Cycle당 bit | 비고 |
|---|---|---|
| AXI read | **256 b/beat** | DDR im2col matrix 읽기 |
| BRAM write (partitioned) | 256 b/cycle/bank | beat N → bank N%4, local addr N/4 |
| 총 용량 | 4 bank × 1024-beat × 256-bit = 128 KB / buffer × 2 (double) = **256 KB** | |
| Read port `rd_data_o` (Mode A) | **256 b/cycle** | 1 bank 선택 출력 |
| Read port wide `rd_data_wide_o` (Mode B) | **1024 b/cycle** | 4 bank 병렬 concat |

### 5.4 hwpe_weight_buf

| 인터페이스 | Cycle당 bit |
|---|---|
| TCDM 32-bit read | 32 b/cycle (LOAD_W phase 중) |
| 내부 FF `weight_q[4][144][16]` | 총 **9,216 bit** 저장 |
| 출력 `weight_o[r][k]` (combinational) | **9,216 b 병렬** — systolic이 `weight_i[r][k_q]` 로 runtime 선택 |

로드 cycle 수 ≈ `out_ch × (in_ch × 9 + 1)` (weight + bias).

### 5.5 hwpe_systolic_array (S_RUN compute)

| 신호 | Cycle당 bit |
|---|---|
| `bram_rd_addr_o` | 8-bit (k index, prefetch k+1) |
| `act_data_i` (Mode A) | **256 b/cycle** = 16 × int16 |
| `act_data_wide_i` (Mode B) | **1024 b/cycle** = 64 × int16 |
| `weight_i[r][k_q]` (Mode A) | 4 row × 16-bit = **64 b/cycle** |
| `weight_i[0][k_q]` broadcast (Mode B) | **16 b/cycle** (모든 64 PE 복제) |
| Per-cycle MAC | 64 × (int16 × int16 → int32 product + int32 accumulate) = **64 MAC/cycle** |
| `acc_o[r][c]` (S_OUTPUT 시점) | 4 × 16 × 32-bit = **2,048 b 병렬** |

### 5.6 hwpe_post_proc (drain + write)

| 신호 | Cycle당 bit |
|---|---|
| `acc_i[ch]` (1 pix/cycle drain) | 4 × int32 = **128 b** (Mode A) |
| `bias_i[ch]` | 4 × int16 = 64 b (상시) |
| `mac_valid_i` | 1-bit pulse train |
| 내부 `buf_q[4][16][16]` | **1,024 b total** |
| `axi_w_data_o` | **256 b/beat** (16 pix × int16) |
| Mode A burst length | ar_len = 0 → 1 beat/channel × out_ch beats |
| Mode B burst length | ar_len = 3 → **4-beat INCR burst** (64 pix in one burst) |

## 6. 데이터 경로 전체 요약 (Mode A 예)

```
DDR3                                        256-bit AXI R/W
  │
  ▼
hwpe_axi_dma (4-bank BRAM)                  256 b write/beat
                                            256 b read (Mode A) / 1024 b read (Mode B)
  │
  ▼
hwpe_systolic (4×16 PE = 64 PE)
  activation  : 256 b/cycle (A) / 1024 b/cycle (B)
  weight      :  64 b/cycle (A) /   16 b/cycle (B, broadcast)
  MAC         : 64 × (int16×int16 → int32) / cycle
  accumulator : 2048 b parallel (drained 1 pix/cycle)
  │
  ▼
hwpe_post_proc
  per-cycle drain : 128 b (A) / 32 b (B)
  fill buffer     : 1024 b (공유 저장소, 해석만 변경)
  AXI out         : 256 b/beat, 1-beat/ch (A) or 4-beat burst (B)
  │
  ▼
DDR3                                        256-bit AXI write
```
